# 网络拓扑

一个安装实例对应一个节点；手机按 `installation_id` 保存多个实例。

## 同网或远程组网

运行节点和 LAN 入口。入口动态端口写入 `lan.json` 与二维码；防火墙仅允许手机所在 LAN 网段或组网接口访问该端口，节点端口保持 loopback。

异地且没有服务器时，只复用用户已经选择并建立的组网：验证 Android 与节点均在线、节点地址稳定且入口端口可达，然后仍按 LAN 形态部署，不运行 FRP 或公网网关。没有现成组网时，向用户说明所需条件并等待其选择与建立；项目不推荐、不安装、不管理具体组网产品。

## Linux 公网服务器

```text
Android ── HTTPS/mTLS ── 443入口 ── 网关状态端口 ── 节点隧道端口
Android ── HTTPS邀请 ─── 443入口 ── 网关配对端口
节点 ───── WSS/443 ───── 443入口 ── FRPS端口
```

四个服务器内部端口均从 `server.json` 读取且只监听 loopback。公网只新增既有 443 流量；22 仅用于既有管理。网关初始化一次生成两端共享的安装 ID、控制令牌和 FRPS token，并用独立隧道 CA 签发 frpc 客户端证书；它们不能复用设备 CA。隧道 CA 私钥只留在服务器，节点只接收 CA 证书和自身客户端身份。
